DAE 완성본 사용 방법

1. DAE.zip을 새 위치에 압축 해제하세요. 이전 패치를 순서대로 적용할 필요가 없습니다.
2. DAE 폴더의 index.html 옆에 기존 portfolio_2026 폴더 전체를 넣으세요.
   최종 경로 예: DAE/index.html, DAE/portfolio_2026/alien/picture/...
3. DAE 폴더에서 PowerShell을 열어 아래 명령을 실행하세요.

   py -m http.server 8000

4. 브라우저에서 http://localhost:8000 을 여세요.
   이미 같은 주소로 열어둔 화면이 있다면 Ctrl+F5로 새로고침하세요.

포함된 파일
- index.html: 자동 슬라이드와 작품 목록
- work-*.html: 작품 10개의 상세페이지
- style.css, projects.css: 전체 스타일
- projects.js, script.js, media.js: 작품 데이터와 동작
- assets/work-previews: 목록용 미리보기, 영상 포스터, 너티밀크 대표사진

별도로 넣을 파일
- portfolio_2026 원본 폴더: 용량이 큰 원본 사진·영상·설명 파일입니다.
  이 ZIP에는 포함하지 않았습니다. 기존 폴더명과 파일명을 유지하세요.
  portfolio_2026 안에 같은 이름의 폴더를 한 번 더 중첩하지 마세요.

반영 내용
- 뒤에 겹친 사진의 보이는 부분에 마우스를 올리면 그 사진 자체가 맨 앞으로 나옵니다.
- 앞으로 나온 사진은 조금 커져서 잘 보이며, 마우스를 묶음 밖으로 빼면 원래 순서로 돌아갑니다.
- 사진이나 제목을 클릭하면 바로 해당 작품의 상세페이지로 이동합니다.
- 사진 묶음 확대와 간격 조정은 INDEX의 작품 목록에만 적용합니다.
- 상세페이지 이미지·영상 폭은 이전 상세페이지 기준을 유지합니다.
  일반 이미지 최대 680px, 가로 대표 이미지/영상 최대 1600px이며 화면 폭 안에서 줄어듭니다.
- 작품명과 년도/분류를 작품 가까이에 왼쪽 정렬합니다.
- 메뉴 뒤 사각 배경을 없애고, 뒤의 배경과 대비되는 글자색을 적용합니다.
- 작품 순서, 설명문, 너티밀크 실제 이미지 4개 연결을 유지합니다.
- 모바일에서는 사진을 한 번 탭하면 상세페이지로 이동합니다.

사이트 주소로 배포할 때
DAE 폴더 안의 index.html, work-*.html, CSS/JS, assets, portfolio_2026을 함께 올리세요.
